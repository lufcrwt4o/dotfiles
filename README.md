# dotfiles

Personal configuration files for macOS and development tools.

## Contents

- **zsh** – shell aliases, prompt, and history settings
- **git** – global gitconfig and aliases
- **vim** – lightweight vimrc
- **scripts** – small utilities for daily tasks

## Usage

Clone this repo and run `install.sh` to symlink the configs into `$HOME`.

## Notes

- Built for zsh + macOS, but most configs are shell-agnostic.
- Always review changes before applying to a new machine.
